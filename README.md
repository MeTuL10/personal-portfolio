# Metul Prabhu — Personal Portfolio (React)

A React application of my personal portfolio, built with **Vite** and deployable to **GitHub Pages**.


## 🛠 Tech Stack

| Tool | Purpose |
|------|---------|
| React 18 | UI framework |
| Vite 6 | Build tool + dev server |
| CSS Modules | Scoped component styles |
| GitHub Actions | CI/CD pipeline |
| gh-pages | Manual deploy fallback |
| Font Awesome | Icons |
| Google Fonts (Syne + Space Mono) | Typography |
